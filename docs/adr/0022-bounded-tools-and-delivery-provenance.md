# ADR-0022: Bounded tools and per-delivery evidence provenance

Status: accepted, 2026-10-02. Keeps ADR-0008, ADR-0013 and lexical BM25F defaults.

## Decision

Keep the five synchronous read-only tools. Return readable escaped note blocks plus a compact versioned summary; persist a typed `ResultContract` alongside each tool result. The contract records effective inputs, accessible research scope, corpus revision, returned units, exact ranked/matching candidate counts, completeness and per-delivery evidence spans. Search candidate counts mean lexical candidates, never all relevant knowledge. Section/revision evidence IDs remain unchanged across scopes. New IDs store the exact vault-relative link path for Copy/Insert so later duplicate basenames cannot redirect a citation; historical ledger entries remain compatible. A title, metadata, outline, preview or graph delivery does not establish body support. The evaluator consumes the exact escaped span text directly; historical traces retain their original parsing path without rewriting recordings.

`read` adds optional `mode: body|outline`, `section_id`, `max_chars`, `source_path` and `cursor`. The default remains an evidence section subtree, a heading subtree, or a bare note body. Repeated headings require outline/section ID selection; parsed chunk continuations are distinguished from repeated sibling headings. Deleted sections return stale-reference errors, never whole-note expansion. Surviving edited sections register a new revision and preserve old IDs. Body offsets are section-relative exclusive character ranges; the canonical body joins parsed sections with a newline. Frontmatter is separate bounded metadata, not part of body reconstruction. Empty notes use a stable empty-section identity.

List and match use deterministic path/section/line ordering, exact totals and pagination. Omitted and empty stage arrays both mean all research stages. Folder/tag filtering is shared by all ranked/survey tools. Match adds optional target scope and up to three context lines, literal/regex and case selection. Regex is a documented fixed-width subset: literals, dot, anchors, classes and elementary character escapes. Groups, quantifiers, alternation, backreferences and property escapes are rejected before execution. This removes unbounded backtracking without native dependencies or sidecars. Matched lines are capped at 300 characters, and the result reports clipping.

Graph counts cover all resolved research-corpus edges independent of displayed-neighbor filters. Self-links count as an incoming and outgoing edge but do not add the root to its neighborhood. Orphan means zero resolved edges in either direction. Traversal supports both/outgoing/incoming directions, at most depth two; each displayed neighbor retains its shortest distance. Unresolved names are separate data. Filtering selects displayed endpoints, while traversal through the accessible graph remains unfiltered. List supports orphan/no-backlinks/no-outlinks and keeps `orphans_only`.

Search adds `per_note` (1–5) and a separate total-section `limit` (1–20). The default remains eight sections, one per note; weights, tokenizer and tie-breaking are unchanged. Matched terms are accurately labeled as found in the note; scores express order only. Search is ranked and capped, without an exhaustion cursor; `hasMore` describes omitted ranked candidates.

Cursors are opaque tokens stored in a bounded in-memory registry per corpus instance (512 recent tokens), bound to query, position and corpus revision. Page-size changes are allowed; changing mode/target/filters or any indexed path/content/stage invalidates the cursor. Restart after expiry, plugin reload or a corpus update. No model-supplied offset is trusted. No persistent cursor capability or vault write API is added.

Tool evidence registration is transactional. The remaining loop character budget includes summaries, wrappers and metadata; an oversized result returns a recoverable output-budget error and registers no undelivered IDs. Attachment contracts persist on the initial user message and their exact output size counts against the turn budget before further tool calls. Provider adapters continue sending text only, while saved chat history keeps structured provenance. UI tool summaries remain compact.

## Validation and limits

Deterministic tests cover oversized sections, many short sections, repeated headings, empty notes, stale citations, forged/stale cursors, filtering, cycles, self-links, two-hop distances, fixed-width regexes, hostile wrapper/attribute data and output budgets. Paid E2E and quality evaluation are deferred at the owner's request. Contract version 1 is new behavior; historical v1 evaluation artifacts and cassettes remain unchanged and cannot establish quality of this implementation.
