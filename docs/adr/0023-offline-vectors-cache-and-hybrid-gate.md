# ADR-0023: Offline exact vectors, host cache and hybrid promotion gate

Status: accepted, 2026-10-02. Implements the experiment boundary in ADR-0008; no production semantic search or database dependency.

## Decision

Add an Obsidian-free embedding-provider port with explicit provider/model/version, dimensions, L2 normalization, cosine metric, batch size, timeout and cancellation. No actual embedding model or prices are selected. Provider outputs must have the correct batch/dimensions, finite nonzero vectors and explicit usage (unknown is null). Deadlines and aborts are enforced even when an adapter ignores its signal. Failed indexing retains accounting with unknown usage rather than assuming a free request.

Representation `title-heading-body-v1` encodes title (at most 500 characters), complete heading path (at most 1000) and the complete indexed section body. Bibliographic metadata is deliberately omitted from this first representation. Record exact encoder input, note path, section ID, note content hash, representation and model identity. Revision invalidation is conservative: any note metadata/content change invalidates its section records. No slicing, automatic model change or paid fallback is allowed on oversize/model/provider failure.

Start with normalized arrays and exact cosine scanning. Filter eligible stage/folder/tag paths before ranking and per-note/top-section limits. The index is unavailable during an incomplete/failed build, stale after a corpus revision change, and published atomically only for a complete unchanged revision. Successfully cached batches survive interrupted builds; obsolete records are pruned during maintenance, including notes removed or reclassified during failures. This work lives outside the Agent tool-control loop.

Caches are derived host infrastructure outside the vault file tree. The filesystem adapter is evaluation-only (`eval/vector-cache.ts`); plain retrieval knows only the cache port. Defaults are `~/Library/Caches/zettel-agent/embeddings/v1` on macOS, `$XDG_CACHE_HOME/zettel-agent/embeddings/v1` or `~/.cache/...` on Linux, and `~/AppData/Local/zettel-agent/embeddings/v1` on Windows. Explicit cache destinations are checked against the canonical vault root, including symlinked parents. Validate cached schemas and identities, use atomic temporary-file rename, and reject symlink entries and traversal keys. No cache API is exported as an Agent tool. Tests/benchmarks use disposable directories outside the fixture vault.

Prepare the section index once; query encoding, scanning and note-body delivery are separate operations. The offline comparison accepts an immutable cached encoder and rejects a cache miss without network fallback. Query cache identity is scoped to one experiment/model and exact query text; account cache hits and encoding latency separately. Query vectors and similarities never establish citable body support. Production remains lexical; asynchronous dispatch and provider/session/UI migration wait for promotion.

Compare BM25F, dense and hybrid with candidate depth 50, cutoff 10, section RRF constant 60, then best-section note deduplication (`perNote=1`). There is no score normalization or keyword-match fabrication. This uses the [RRF formula documented by Elastic](https://www.elastic.co/docs/reference/elasticsearch/rest-apis/reciprocal-rank-fusion), with ranks starting at one. Generate a union top-ten pool with null/unreviewed labels. Scoring requires a new explicitly frozen matching corpus/protocol/label version and a judgment for every pooled candidate. Retain original v1 labels/results. AI review stays AI review. All retrievers use that same new pool.

Before inspecting genuine semantic scores, require at least +3 percentage points in development R@10 or MRR@10, at most −2 points in the other metric and no more than −2 points in the exact-term slice. Bind query/filter/family/slice identities with the frozen label version. Report denominators and seeded paired source-family cluster bootstrap intervals (descriptive, not calibrated label uncertainty); paired answer grounding, citation coverage, cost/latency and a fresh frozen final checkpoint are additional mandatory gates. Test-vector results cannot pass a quality gate. The offline benchmark makes no semantic quality claim and cannot promote production.

## Deferred decisions

A model adapter/configuration, monetary allowance, genuine section/query vectors and reviewed pooled labels are pending the owner's explicit resumption of paid work. No actual embedding, solver, judge or E2E request runs in this phase. A database/ANN index is conditional on measured interactive requirements; scan p95 target is 100 ms excluding query encoding. No native add-on, sidecar or external service is introduced. Benchmark an embedded index before adopting infrastructure if a representative workload exceeds the target.
