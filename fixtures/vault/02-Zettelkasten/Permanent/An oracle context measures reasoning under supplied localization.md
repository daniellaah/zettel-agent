# An oracle context measures reasoning under supplied localization

Providing the files touched by a known solution removes part of the localization problem. The resulting score can diagnose behavior with that assistance, but does not measure the same system as retrieval from the entire repository. Reporting oracle and ordinary retrieval results separately keeps the source of that assistance visible.
