# Retrieval practice beats rereading

Pulling an idea out of memory strengthens it far more than looking at it again. Rereading feels productive because the text becomes familiar, but familiarity is recognition, not recall — being able to nod along is not the same as being able to reproduce the argument with the page closed.

Anything that forces reconstruction counts: a low-stakes quiz, a blank-page summary, answering a question before opening the notes, explaining the idea to someone else. The effort of reconstruction is what makes the memory durable. The benefit holds even when the attempt fails, as long as I check the answer afterwards; a failed retrieval followed by feedback still beats a successful reread.

My working rule: close the source, write down what I remember, then compare and fix the gaps.
