# Per-user recall gives users equal weight rather than interactions

Averaging recall for each user gives equal aggregate weight to users even when their target sets differ in size. Pooling all relevant interactions would give more influence to users with larger target sets. Neither aggregation is implied by the word recall. This parallels [[Equal user sampling changes whose errors dominate training]]: weighting determines whose outcomes dominate a reported objective or metric.
