# Tool output size and evidence usefulness are separate quantities

A large response can contain much information while making the relevant evidence difficult to locate or use. Context-efficient tools should retain the facts and structure necessary for decisions rather than maximizing returned text. The long-context position experiments provide another reason to evaluate evidence use directly: putting more text into the context is not a sufficient quality objective.
