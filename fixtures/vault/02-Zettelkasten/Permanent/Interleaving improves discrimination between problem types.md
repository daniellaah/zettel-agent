# Interleaving improves discrimination between problem types

Blocked practice (AAA, BBB, CCC) lets me apply the same method over and over without ever deciding which method fits. Every problem in the block announces its own type. Interleaved practice (A, C, B, A, B, C ...) removes that label, so each problem forces the decision "what kind of problem is this?" — which is precisely the skill a real exam or interview tests.

A side effect is that practice on any one type gets stretched out over a longer stretch of time instead of being done in a single burst, which helps retention on its own.

The cost is that interleaved sessions feel slower and more frustrating, and scores during practice are lower. Learners who compare the two by how the session felt will almost always choose blocking.

My case: grinding twenty two-pointer problems in a row felt great; facing an unlabeled problem in an interview did not.
