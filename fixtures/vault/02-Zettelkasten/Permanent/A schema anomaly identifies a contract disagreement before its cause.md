# A schema anomaly identifies a contract disagreement before its cause

A value outside an expected domain can represent a collection defect or a legitimate change in the product. Detection establishes a disagreement with the current contract, not which explanation is correct. Resolving it requires deciding whether to repair the data or revise the schema, with ownership of that decision made explicit.
