# A long context window does not guarantee uniform evidence access

Accepting many tokens establishes an input capacity, not a guarantee that every position contributes equally to an answer. Controlled evidence relocation can reveal sensitivity hidden by a single aggregate benchmark. The Lost in the Middle results motivate measuring position effects for the models actually deployed; they do not establish an identical failure curve for every later model or task.
