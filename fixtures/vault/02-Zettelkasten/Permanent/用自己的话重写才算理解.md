# 用自己的话重写才算理解

摘抄只是把文字从一个地方搬到另一个地方，搬的过程中不需要理解。把 fleeting note 或文献摘录变成永久笔记时，我给自己的规则是：合上原书，不看摘录，用自己的词汇把意思重新写出来。

写不出来，说明刚才只是"看懂了句子"，没有懂论证。写出来之后再和原文对照，差异通常出现在原文作者一笔带过、而我也跟着跳过的那一步推理上。这一步就是真正需要补的地方。

另一个实际规则：fleeting notes 要在一两天内处理。拖到一周以后，当时为什么觉得这句话重要的上下文已经丢了，只剩一行看不懂的字。
