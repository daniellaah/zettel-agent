# 双塔模型把召回变成最近邻搜索

双塔（two-tower）模型分别把 user 和 item 编码成同一空间里的向量，打分只是两者的内积。关键在于 item 塔完全不依赖 user：所有 item 向量可以离线算好，放进 ANN 索引。线上召回因此退化成一次最近邻搜索，从百万级候选里取出几百个。

代价是 user 特征和 item 特征之间没有任何早期交叉，表达能力明显弱于精排模型。所以它适合做召回（retrieval），不适合做最终排序。

线上 serving 的打分就是纯内积，训练时加在 logit 上的各种修正项（温度、采样概率的对数之类）都不会进入索引。索引里存的就是 item 塔的原始输出。

## 关联
- 训练难点 [[In-batch negatives oversample popular items]]：双塔通常用 batch 内的其他正样本当负样本来训练。
- 评估方式 [[Recall@k 只衡量候选集而非最终排序]]：召回阶段只关心候选集有没有覆盖到正样本。
