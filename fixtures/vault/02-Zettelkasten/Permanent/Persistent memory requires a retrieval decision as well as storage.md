# Persistent memory requires a retrieval decision as well as storage

Writing information outside the current context preserves it, but it does not ensure that a later decision will use it. The system must select and reintroduce the relevant record when needed. Memory quality consequently involves both what is saved and how it is retrieved. This connects long-task continuity to ordinary evidence selection rather than treating persistence as sufficient by itself.
