# Bootstrap duplicates represent resampling rather than additional evidence

Repeated rows in a bootstrap sample change the weight of existing observations. They do not add newly observed information to the original dataset. Increasing the number of bootstrap repetitions can stabilize an estimate of variability, but cannot supply population patterns missing from the observations being resampled.
