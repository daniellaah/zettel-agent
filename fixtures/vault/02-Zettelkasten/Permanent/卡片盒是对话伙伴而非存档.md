# 卡片盒是对话伙伴而非存档

Luhmann 把他的卡片盒描述成一个能让他感到意外的交流对象。存档按主题存放，取出来的东西和放进去的一模一样；对话伙伴则会给出你没预料到的回应。

意外来自内部的交叉引用网络。顺着链接往下走，会遇到多年前写的、早已忘记的卡片。这意味着卡片盒的价值取决于链接的密度和质量，而不是笔记的数量。

Luhmann 的固定编号允许在任意位置插入新卡片，让一条思路可以不断分叉。编号的细节另记在 [[Folgezettel 编号规则]]（还没写）。

这也是我想做研究 agent 的动机：让系统替我顺着链接多走几步。
