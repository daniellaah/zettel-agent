# Latent factor sharing can estimate a pair that was never observed

An unobserved pair can receive a nonzero interaction score when its features have learned factors through other observations. This is possible because pair coefficients share feature parameters instead of being independent. The estimate is a model-based generalization, not direct evidence about that particular pair. Its usefulness depends on whether the shared factor structure captures relationships relevant to the prediction target.
