# Joint support requires evaluating the cited set rather than isolated passages

Some statements require evidence distributed across several passages. Demanding that every citation independently establish the complete claim can wrongly reject useful partial support. Conversely, adding irrelevant references can inflate apparent coverage. A citation assessment should examine whether the set supports the statement and whether each member contributes, reflecting the distinction between coverage and precision.
