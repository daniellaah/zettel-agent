# Multiple retrieval vectors preserve distinct matching directions

A single user vector gives every candidate one shared matching direction. Several interest vectors let an item match a specific part of the history without requiring that direction to survive an average across unrelated behaviors. Maximum scoring preserves a strong local match. This expands representation capacity, but it does not guarantee that every interest appears in the final recommendation list.
