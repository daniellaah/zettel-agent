# A better draft model is one that agrees with the target distribution

Draft proposals are useful when the target accepts them. Agreement with the target is therefore the relevant quality signal for acceleration, which can differ from accuracy against an external answer label. A more capable draft may also cost more to run; selecting it requires considering both agreement and draft latency.
