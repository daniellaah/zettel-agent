# An observation should be able to change the next action

Interactive research gains value when external evidence changes what the agent does next. A failed search can motivate reformulation, and a discovered fact can narrow a remaining question. Merely issuing tools in a predetermined sequence does not demonstrate this adaptation. Inspecting how later actions depend on observations helps determine whether the loop is using evidence or only decorating an existing plan.
