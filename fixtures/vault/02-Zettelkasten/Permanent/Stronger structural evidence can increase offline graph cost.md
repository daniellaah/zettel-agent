# Stronger structural evidence can increase offline graph cost

Adding user-pair structure changes the amount of work required to build item relationships. Parallel construction can distribute this work, but it does not remove the underlying dependence on neighborhood size. Comparing graph methods therefore requires separating retrieval-time lookup cost from construction cost. An inexpensive lookup table may have been produced by a substantially more expensive offline computation.
