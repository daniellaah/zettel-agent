# Agent autonomy belongs to the orchestration policy

A system's autonomy depends on who chooses its next steps and tools. A language model inside a fixed pipeline does not automatically make that pipeline an autonomous agent. This distinction helps describe capabilities concretely: identify the decisions delegated to the model and those enforced by code. The same model can participate in systems with very different control boundaries.
