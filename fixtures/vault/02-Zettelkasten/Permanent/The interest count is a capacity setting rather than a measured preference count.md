# The interest count is a capacity setting rather than a measured preference count

An adaptive interest-count heuristic allocates model capacity from history length. It does not measure the number of real preferences a person has. More slots also imply more candidate searches and possible overlap. The choice should therefore be understood as a representation and serving-budget decision, with enough history to support the allocation, rather than as a literal psychological interpretation of the user.
