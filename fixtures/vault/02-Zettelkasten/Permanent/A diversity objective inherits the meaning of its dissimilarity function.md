# A diversity objective inherits the meaning of its dissimilarity function

A category-based dissimilarity reward encourages category differences among selected items. It does not directly measure novelty, coverage of every user interest, or satisfaction. The proxy defines what the optimizer treats as diverse. Choosing the coefficient changes the tradeoff within that definition; it cannot make the definition capture a different concept without changing the underlying dissimilarity signal.
