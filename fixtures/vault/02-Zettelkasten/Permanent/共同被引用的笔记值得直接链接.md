# 共同被引用的笔记值得直接链接

两张卡片如果经常同时出现在同一张结构笔记、同一篇草稿的引用列表里，彼此却没有直接链接，那它们之间多半有一个我还没写出来的关系。

co-citation 是比关键词重合更好的信号。关键词重合只说明用词相似；共同被引用说明我在思考时反复把它们放在一起用。

但要打折：像索引这样几乎链接了所有东西的 hub 笔记，它产生的共引几乎没有信息量；一张只引用了三四张卡片的草稿，它产生的共引才有分量。引用面越窄，证据越强。

共引只能给出候选。真正建立链接之前，仍然要我写出一句理由；写不出理由的候选就丢掉。

## 关联
- 约束 [[链接必须写明理由]]：共引只提供候选，理由还得我自己写。
- 服务于 [[卡片盒是对话伙伴而非存档]]：链接越密，卡片盒越可能给出意外的回应。
