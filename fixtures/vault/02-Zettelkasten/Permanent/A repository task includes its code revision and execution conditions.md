# A repository task includes its code revision and execution conditions

An issue description alone does not identify the code on which a repair is evaluated. The base revision, test patch, dependencies, and execution conditions can change whether a proposed fix applies or succeeds. Reproducible task identity therefore needs those conditions alongside the natural-language problem statement.
