# A success claim should be checked against the resulting state

An agent can state that it completed a task while leaving the required environment unchanged. Grading the final state distinguishes accomplished work from a plausible completion message. For a read-only research agent, the analogous outcome may be a supported answer rather than a mutation, but the same principle applies: success criteria should refer to the actual deliverable and evidence, not the agent's self-assessment.
