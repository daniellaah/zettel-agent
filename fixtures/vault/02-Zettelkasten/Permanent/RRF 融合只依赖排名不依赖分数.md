# RRF 融合只依赖排名不依赖分数

bm25 的分数没有上界，而且随查询长度变化；余弦相似度落在 [-1, 1]。把两路分数直接加权求和之前必须先归一化，而归一化方式（min-max、z-score、按最高分截断）对最终结果的影响往往比权重本身还大。

RRF 绕开了这个问题：每个文档的融合分数是它在各路结果中的 1/(k + rank) 之和，k 通常取 60。只用排名意味着任何检索器都可以即插即用，不需要校准分数。

代价是丢掉了分数间距的信息：某一路里第一名遥遥领先，和第一名只是险胜，在 RRF 看来是一样的。k 越大，排名靠后的文档被压得越轻。

在我的场景里，hybrid 的收益主要来自两路检索结果的互补，而不是融合公式本身。
