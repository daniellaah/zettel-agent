# Residual correction is essential to distribution-preserving draft acceptance

Keeping likely draft tokens and resampling rejected ones directly from the target does not in general recover the target distribution. The residual distribution compensates for probability mass already supplied through accepted proposals. This correction is a substantive part of exact speculative sampling, not an interchangeable rejection fallback.
