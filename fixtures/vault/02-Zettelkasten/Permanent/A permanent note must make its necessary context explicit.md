# A permanent note must make its necessary context explicit

An idea can be reused after its original reading context has been forgotten only when the note preserves enough information to understand it. This includes the claim, the reasoning or example that makes it intelligible, and any qualifications that affect its scope. A source reference preserves provenance; the explanation within the note enables understanding.

When developing a permanent note from a literature note, ask: could I understand this claim and its justification without reopening the original text? Any missing premise, definition or qualification should be made explicit.
