# Rating-scale correction is distinct from popularity correction

Subtracting a user mean adjusts how that person uses a rating scale. Downweighting highly active users or broad user-pair overlap changes the contribution of behavioral support. These transformations address different statistical effects. Applying one does not establish that the other has been handled, and transferring explicit-rating adjustments directly to binary clicks requires reconsidering what the values represent.
