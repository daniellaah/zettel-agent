# User-disjoint evaluation tests a different generalization boundary

Holding out users asks whether a model can infer useful representations from the histories of people absent from training. Holding out later events for already-seen users asks a different question. An evaluation can impose both boundaries, as the ComiRec protocol does within its held-out users. Comparing results requires stating these boundaries because a metric name alone does not describe the prediction difficulty.
