# Pseudo feedback can amplify an initial interpretation error

Automatic feedback treats the initial top results as evidence about the intended need. If those results reflect the wrong sense of an ambiguous query, expansion can reinforce that interpretation rather than correct it. The method's usefulness consequently depends on the quality of its starting evidence. Adding more query terms is not automatically adding more accurate information about user intent.
