# Interest extraction and list diversity solve different problems

Distinct interest vectors can still retrieve overlapping candidates, and relevance sorting can favor one interest throughout the final list. Representation diversity therefore does not establish output diversity. A separate selection objective can reward differences among selected items. The connection between extraction and selection is candidate availability: an aggregation rule cannot select an interest that candidate retrieval never exposed.
