# 分词器会吃掉符号

给笔记搜索写 bm25 时踩的坑，先记下来。

## C# 和 C++
默认用正则 `\w+` 分词，C#、C++ 都被切成 `c`，于是搜 C# 会命中所有提到 C 语言的笔记。要加一个保留符号的白名单（C#、C++、F#、.NET）。

## 中文
jieba 对"卡片盒"有时切成 卡片 / 盒，有时整体保留，词典一变结果就变。先用字符 bigram 兜底，至少稳定。单字查询怎么办还没想好。

## 大小写
BM25 和 bm25 要归一成同一个 token，LogQ / logq 也一样。
