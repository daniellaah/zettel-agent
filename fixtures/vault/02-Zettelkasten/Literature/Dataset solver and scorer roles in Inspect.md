# Dataset solver and scorer roles in Inspect

Inspect tasks combine a dataset, a solver, and a scorer. Solvers execute the process that produces an output, using either composed components or custom code for interactions and agent scaffolds. Scorers compare outputs with targets using text matching, model grading, or other rubrics. They also define aggregation metrics. The documentation separates the execution strategy from the criteria used to assess its results.
