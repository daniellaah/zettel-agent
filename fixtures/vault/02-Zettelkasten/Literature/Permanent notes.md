# Permanent notes

Main notes in the slip-box express ideas in a form that can remain understandable after the original reading or thinking situation has been forgotten. Ahrens asks the writer to develop one note for each idea, using complete sentences, clear expression, disclosed sources and relevant references. These notes contain the thought itself rather than merely reminding the writer that a thought once occurred. Keeping each note focused on one idea allows it to be combined with other ideas in different arguments.

Creating a main note involves considering how an idea relates to existing interests and discussions. New information may support, contradict, correct or extend what is already there, or raise another question. The completed note is then integrated through connections with relevant notes and a route by which it can be found again. The process develops thought rather than simply enlarging a collection of excerpts.

Main notes are retained even when they later receive little attention; their future usefulness cannot always be decided when they are written. Ahrens also distinguishes permanent retention from the narrower main-note role: literature records remain in the reference system, while developed main notes belong in the slip-box. Project-specific material is kept separately so that a temporary project does not determine the limits of the lasting collection.
