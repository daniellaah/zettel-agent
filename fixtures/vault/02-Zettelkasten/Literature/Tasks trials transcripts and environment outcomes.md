# Tasks trials transcripts and environment outcomes

The article distinguishes an evaluation task from a trial, with repeated trials helping measure variable agent behavior. Graders score aspects of performance and may contain multiple checks. A transcript records the interaction trajectory, whereas an outcome is the final state of the environment. An agent evaluation measures the model together with its harness, including orchestration and tools, rather than treating the model name as the complete system.
