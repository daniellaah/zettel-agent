# Counterfactual logging for affected traffic

Counterfactual logging records whether a control request would have received the experimental feature under treatment assignment. This permits identifying comparable affected traffic in both variants even when the feature is absent from control. The article uses a weather-answer example to explain more sensitive analysis of the relevant population. It recommends validating the logging and checking sample-ratio mismatch so that the selected comparison does not miss affected users.
