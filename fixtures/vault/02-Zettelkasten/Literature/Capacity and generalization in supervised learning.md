# Capacity and generalization in supervised learning

The book distinguishes reducing training error from achieving low expected error on previously unseen inputs. Model capacity describes the variety of functions a model can fit. Insufficient capacity can prevent fitting the training problem, while excessive capacity relative to the available task and data can fit details that do not generalize. Selecting a hypothesis space is one way to control capacity; the book illustrates this using polynomial regression.
