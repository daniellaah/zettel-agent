# Structured notes outside the agent context window

Structured note-taking stores information outside the current context window and brings those records back into context later. The article describes agents maintaining task progress, critical dependencies, and strategic notes across long sequences of tool calls. Its examples include a task list or a dedicated notes file. After a context reset, an agent can read the stored records and continue work using information that would otherwise have left its active context.
