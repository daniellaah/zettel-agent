# Tool contracts and minimal agent context

The article describes tools as the interface through which an agent obtains information and acts on its environment. It recommends clear, self-contained tools with descriptive parameters, robust errors, and minimal overlap in functionality. Large overlapping tool sets can create ambiguous choices and consume context. It also favors diverse representative examples over exhaustive edge-case instructions, and recommends keeping context informative while limiting unnecessary material.
