# Precomputed item neighborhoods for scalable prediction

The paper describes item similarity as more static than user similarity and uses this to precompute neighborhoods for item-based prediction. Its performance investigation examines how the size of that neighborhood model affects response time and throughput. Similarity construction and recommendation generation are therefore evaluated as connected parts of the system, with a reusable item model supplying neighborhoods for later personalized predictions.
