# User-pair evidence in Swing similarity

Swing computes item similarity from pairs of users who clicked both items. For each contributing user pair, the score is divided by a smoothing term plus the number of items shared by those users. The paper uses this structure to distinguish support from multiple users from an isolated click connection. It further multiplies contributions by user weights that decrease with the number of items each user has clicked.
