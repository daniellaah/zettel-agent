# Assumed relevance in pseudo relevance feedback

Pseudo relevance feedback first retrieves results using the original query and then assumes that a chosen number of top-ranked documents are relevant. It uses those documents to perform automatic query refinement without asking the user for judgments. The book reports benefits in retrieval experiments while warning that the assumption can cause problems when the initial results emphasize an unintended meaning of the query.
