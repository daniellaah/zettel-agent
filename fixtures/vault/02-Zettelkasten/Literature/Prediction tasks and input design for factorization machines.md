# Prediction tasks and input design for factorization machines

Factorization machines accept real-valued feature vectors, including indicator features for users and items and additional contextual features. The same score function can be used for regression, binary classification, or ranking. The paper describes squared-error regression, hinge or logistic classification losses, and pairwise ranking losses. These applications change the optimization criterion while retaining the factorized interaction model and its input representation.
