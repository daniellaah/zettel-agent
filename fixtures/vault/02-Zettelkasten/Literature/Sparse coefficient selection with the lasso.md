# Sparse coefficient selection with the lasso

The lasso replaces the squared-coefficient penalty of ridge regression with the sum of absolute coefficient values. A sufficiently strong penalty can set some coefficients exactly to zero, producing a model that uses a subset of predictors. The book illustrates this selection through the corners of the constrained coefficient region. The tuning parameter determines how much the coefficients are constrained.
