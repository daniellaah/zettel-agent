# Bootstrap resampling for estimator variability

The bootstrap approximates repeated sampling from a population by repeatedly sampling observations from the available dataset. Each bootstrap sample has the original sample size and is drawn with replacement, so an observation may occur several times or be absent. The estimator is recomputed on each sample. The book uses the standard deviation of these estimates to approximate the estimator standard error.
