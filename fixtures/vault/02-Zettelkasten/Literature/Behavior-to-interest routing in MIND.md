# Behavior-to-interest routing in MIND

MIND adapts capsule routing to aggregate variable-length behavior histories into interest vectors. It shares one bilinear mapping across behavior and interest capsules so that the resulting representations occupy a common vector space. Because shared mappings and identical routing initialization would produce identical interest capsules, the routing logits are initialized with Gaussian noise. Routing repeatedly computes assignment weights, aggregates the transformed behavior embeddings, and updates agreement between behavior and interest capsules.
