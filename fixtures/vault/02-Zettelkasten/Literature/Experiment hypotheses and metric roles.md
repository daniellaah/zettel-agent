# Experiment hypotheses and metric roles

The article recommends a clear, testable hypothesis describing the expected treatment effect. Metrics must be capable of supporting or contradicting that hypothesis. A core metric set should cover user satisfaction, guardrails, feature engagement, and data quality across experiments. Power calculations should account for the portion of randomized traffic actually affected by a change, rather than assuming that all assigned users experience the treatment.
