# Evidence position in long-context question answering

The paper changes the position of an answer-containing passage while keeping other retrieved passages as distractors. It also changes context length by varying the number of distractors. Across the evaluated models, performance often improves when relevant information is near the beginning or end and decreases when it is in the middle. The question-answering setup contains one annotated answer passage and uses answer occurrence in generated output as its accuracy criterion.
