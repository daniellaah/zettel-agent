# Adaptive interest count in MIND

MIND sets a user-specific number of interest capsules from the base-two logarithm of the number of historical behaviors, bounded below by one and above by the configured maximum. The paper presents this as a heuristic for allocating capsules to different users. Algorithm 1 computes this number before routing. The authors describe reduced computation and memory use for users assigned fewer capsules.
