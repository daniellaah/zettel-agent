# Interleaved reasoning and external actions in ReAct

ReAct interleaves language reasoning with task-specific actions and observations. Reasoning can decompose a question, track progress, extract information, and reformulate a search after an observation. For question answering and fact verification, the paper provides Wikipedia search, lookup, and finish actions and manually composed few-shot trajectories. It notes that this deliberately limited retrieval interface is weaker than contemporary lexical or neural retrievers, because it is designed to require explicit interactive search.
