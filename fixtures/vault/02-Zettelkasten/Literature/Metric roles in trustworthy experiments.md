# Metric roles in trustworthy experiments

The article distinguishes data-quality metrics that assess telemetry reliability, overall evaluation criteria that reflect the product goal, local diagnostic metrics that explain feature behavior, and guardrails that track outcomes that should not deteriorate. It recommends a complete metric set to detect improvements and unintended regressions across product aspects. The taxonomy is intended to guide both metric design and interpretation of experimental movements.
