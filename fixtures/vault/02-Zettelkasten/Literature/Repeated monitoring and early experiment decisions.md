# Repeated monitoring and early experiment decisions

The article recommends inspecting a small critical set of metrics as an experiment runs so that regressions can be detected promptly. It also warns that repeated measurements require statistical methods accounting for multiple testing and early peeking. Microsoft's described procedure requires stronger evidence for early decisions and otherwise recommends completing the predetermined duration before adopting the final observed metric movements.
